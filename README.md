# 칠복장어 — 이용약관과 개인정보처리방침

매장 업무 앱의 법적 고지 문서입니다. 앱스토어·플레이스토어가 **로그인 없이 열리는
주소**를 요구해서 이 레포만 공개로 둡니다. 앱 소스는 별도의 비공개 레포에 있습니다.

- [개인정보처리방침](https://stack-son.github.io/cillbouk-legal/privacy.html)
- [이용약관 · 위치기반서비스 이용약관](https://stack-son.github.io/cillbouk-legal/terms.html)

## 고칠 때

이 파일들을 직접 고치지 마세요. 앱 레포에서 글 한 벌(`src/lib/legal-content.json`)을
고친 뒤 `npm run legal` 을 돌리면 `docs/` 에 다시 구워집니다. 그것을 여기로 옮깁니다.

앱 화면과 이 페이지가 같은 글을 읽게 하려는 것입니다 — 한쪽만 고치면 앱에는 새
방침이, 스토어에 낸 주소에는 옛 방침이 걸려 있게 됩니다.
